Mulai dari pertanyaan publik, tindak lanjut tetap manual

Ekspor hasil pencarian Threads ke file lokal, lalu impor secara eksplisit. Tracker tidak membuka Threads atau mengirim pesan.

  1. Temukan calon dengan pencarian publik: mkdir -p _kerja/lead-tracker && node tools/threads-scntr.mjs cari "minta rekomendasi parfum" --json > _kerja/lead-tracker/threads-hasil.json
  2. Masukkan hasil ke tracker (aman dijalankan ulang; URL duplikat dilewati): node tools/lead-tracker/import-threads.mjs _kerja/lead-tracker/threads-hasil.json
Impor daftar URL lama
  1. State lama hanya menyimpan URL, bukan isi posting. Impor tetap menandai konteksnya sebagai perlu tinjau, tanpa mengarang isi: node tools/lead-tracker/import-threads.mjs _kerja/threads-lead.json

Workflow: tinjau → tandai sudah dibalas manual → catat minat/klik → tandai order setelah terkonfirmasi. Catatan disimpan lokal saja.

Database file: _kerja/lead-tracker/leads.json · Data tidak dikirim ke layanan eksternal.
